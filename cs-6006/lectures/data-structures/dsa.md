## Data Structure and Interfaces

### Data Structures

A Data structure is a way to store data, along with algorithms (and implementations)
that can be performed on the data structure.

### Interface

This is the specification, of what a data structure would look like, what information
it would store and what operations it would support.

### Interfaces vs Data Structures

Interfaces specify what operations can be performed, and Data structures are the
actual implementation of those operations.

## Sequence Interface

Order of items is extrinsically controlled.

### Supported operations

- **build(x)** : given an iterable X, build sequence from item in X.
- **len** : return the number of stored items.
- **iter_seq** : return the stored items one-by-one in sequence order.
